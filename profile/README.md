### ※ Briefing

Kerbangelion is a mod inspired by Evangelion, which aims to bring Eva's Second Impact environment into KSP. Expect cursed conditions, a ravaged Earth, lots of flooding and some more...

### ※ Installation

The mod is split into a few parts you can download:

| Repository | Role |
|---|---|
| [Kerbangelion-Core](https://github.com/Kerbangelion/Kerbangelion-Core) | Mod core |
| [KSCSwitcher-Extended](https://github.com/Kerbangelion/KSCSwitcher-Extended) | Adds support for Tabgha Moon Base |
| [COMING SOON] | /// |

### ※ Requirements:

- A working installation of **Sol**
- x16 Earth and Moon textures
